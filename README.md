# 👋 Olá! Bem-vindo(a) ao meu Diário de Bordo em JavaScript!

## 🚀 Sobre Este Repositório

Este repositório é o meu **cantinho de estudos** e o registro da minha jornada de aprendizado em **JavaScript**. Como estou na fase introdutória, aqui você encontrará os primeiros passos, exercícios básicos e pequenos projetos que me ajudaram a entender a lógica e a sintaxe fundamental da linguagem.

É um espaço de **evolução contínua** e um lembrete de que todo grande desenvolvedor começou com um simples `console.log('Hello World!');`.

## ✨ Meus Primeiros Projetos

A melhor forma de aprender é colocando a mão na massa! Estes são alguns dos exercícios e projetos simples que desenvolvi:

1.  **`calculadora-simples/`**: Uma calculadora básica que realiza as 4 operações fundamentais.
2.  **`lista-de-tarefas-cli/`**: Um pequeno script para gerenciar uma lista de tarefas (To-Do List) no console.
3.  **`contador-de-caracteres/`**: Uma função que recebe uma string e retorna o número de caracteres.

*(Sinta-se à vontade para explorar as pastas! O código pode não ser perfeito, mas é o meu aprendizado em ação!)*
